\section{Simulation and Verification}

Để thực hiện kiểm định thiết kế, nhóm em sử dụng kiểu dữ liệu \texttt{shortreal} của SystemVerilog để thực hiện làm một golden module như sau:

\begin{lstlisting}[style=StyleCode, language=SystemVerilog, caption={Hàm golden model để thực hiện test.}]
	function automatic shortreal Cal_FPU_expected(
		input logic         f_i_add_sub ,
		input shortreal     f_i_32_a    ,
		input shortreal     f_i_32_b            
	);
		begin
			return (f_i_add_sub) ? f_i_32_a - f_i_32_b : f_i_32_a + f_i_32_b;
		end
	endfunction
\end{lstlisting}

Nhóm em sử dụng các test theo sai số, với sai số nhóm em chọn là: 
\[ \text{Error\_standard} = \dfrac{2.0^{-23}}{1.0} \times 100 \approx 11.9209\,\mu\% \]
Có nghĩa là sai ở bit LSB của Mantissa.

Tiếp theo, ta thực hiện xây dựng hàm tính sai số giữa kết quả của golden model và kết quả từ bộ DUT,

\begin{lstlisting}[style=StyleCode, language=SystemVerilog, caption={Hàm tính sai số giữa kết quả của DUT và kết quả của golden model để thực hiện test.}]
	function automatic shortreal Error_actual(
		input shortreal         f_i_32_s    ,
		input shortreal         f_i_32_e     
	);
		logic [31:0] f_t_32_s, f_t_32_e;
		logic is_E_one_S, is_E_one_E;
		logic is_M_zero_S, is_M_zero_E;
		logic is_INF_S, is_INF_E;
		logic is_NAN_S, is_NAN_E;
		
		begin
			f_t_32_s    = REAL_TO_HEX(f_i_32_s);
			f_t_32_e    = REAL_TO_HEX(f_i_32_e);
			is_E_one_S  = &f_t_32_s[30:23];
			is_M_zero_S = ~|f_t_32_s[22:0];
			is_INF_S    = is_E_one_S & is_M_zero_S;
			is_NAN_S    = is_E_one_S & ~is_M_zero_S;
			is_E_one_E  = &f_t_32_e[30:23];
			is_M_zero_E = ~|f_t_32_e[22:0];
			is_INF_E    = is_E_one_E & is_M_zero_E;
			is_NAN_E    = is_E_one_E & ~is_M_zero_E;
			
			if(is_NAN_S) begin
				Error_actual = (is_NAN_E) ? 0.0 : 100.0;
			end else if(is_NAN_E) begin
				Error_actual = (is_NAN_S) ? 0.0 : 100.0;
			end else if(is_INF_S || is_INF_E) begin
				Error_actual = (f_t_32_s == f_t_32_e) ? 0.0 : 100;
			end else if((f_i_32_e == 0.0) || (f_i_32_e == -0.0)) begin
				Error_actual = ((f_i_32_s == 0.0) || (f_i_32_s == -0.0)) ? 0.0 : 100.0;
			end else begin
				Error_actual = ((ABS_value(f_i_32_e - f_i_32_s)) / ABS_value(f_i_32_e)) * 100.0;
			end
		end
	endfunction
\end{lstlisting}

Với xử lý các trường hợp như sau: 

\begin{itemize}
	\item Nếu kết quả của DUT là một NaN-(Not A Number), hoặc kết quả của bộ golden model là NaN, và khi kiểm tra trường hợp có xuất hiện NaN thì không quan tâm đến dấu của phép tính, vậy ta có kết quả sẽ kiểm tra như sau:
		\begin{itemize}
			\item Nếu cả hai đều là NaN thì $\text{Error\_actual} = 0.0 \%$
			\item Còn nếu một kết quả là NaN còn kết quả còn lại không phải là NaN thì $\text{Error\_actual} = 100.0 \%$
		\end{itemize}
	\item Nếu kết quả của DUT là một $\pm \infty$, hoặc kết quả của bộ golden model là $\pm \infty$, thì kiểm tra kết quả của bộ DUT và golden model có giống nhau không:
		\begin{itemize}
			\item Nếu cả hai giống nhau thì $\text{Error\_actual} = 0.0 \%$
			\item Còn nếu hai kết qua không giống nhau thì $\text{Error\_actual} = 100.0 \%$
		\end{itemize}
	\item Còn các trường hợp còn lại thì thực hiện việc tính sai số như sau:
	\[ \text{Error\_actual} = \dfrac{| \textsf{f\_i\_32\_e} - \textsf{f\_i\_32\_s} |}{| \textsf{f\_i\_32\_e} |} \times 100.0\]
\end{itemize}
